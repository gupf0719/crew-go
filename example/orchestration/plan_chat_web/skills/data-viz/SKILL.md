## 业务问题 → 图表推荐速查

| 业务问题 | 推荐图表 | 反推荐 |
|---|---|---|
| 时序趋势 (单序列) | 折线图 | 柱状图 (浪费墨) |
| 时序对比 (多序列) | 多折线 / 小图集 | 双 Y 轴 (扭曲对比) |
| 分类对比 (≤ 7 类) | 横向条形图 | 饼图 (≤ 3 切片才合理) |
| 分类对比 (> 7 类) | 树图 (treemap) | 饼图 |
| 分布 (单变量) | 直方图 / KDE | 箱线图 (只看 quartile) |
| 分布 (多组) | 小提琴图 / 分面直方图 | 散点图 |
| 相关性 (2 变量) | 散点图 + 回归线 | 折线图 (暗示时序) |
| 相关性 (多变量) | 散点矩阵 / 热力图 | 折线图 |
| 组成比例 (单时点) | 堆叠柱 / 树图 | 3D 饼图 |
| 组成随时间变化 | 河流图 / 堆叠面积 | 多饼图 |
| 地理分布 | 地图热力 / 气泡图 | 条形图 |
| 流程 / 漏斗 | 漏斗图 / 桑基图 | 普通条形 |
| 网络关系 | 网络图 (force layout) | 表格 |

## 数据量适配

- **< 100 点**: 任意图都能跑
- **100-10K 点**: 散点用半透明 (alpha=0.3) 防遮挡
- **10K-1M 点**: 用 hexbin / datashader 聚合
- **> 1M 点**: WebGL (plotly scattergl / echarts) 或采样 (1% sample)

## 规则

1. **业务问题驱动**: 业务问"看什么"不是"画什么图", 模型推断意图后推荐
2. **代码可跑**: 给具体配置不是 pseudocode (业务能直接 paste 跑)
3. **反推荐**: 必给"不要用什么图" + 理由 (避免业务踩坑)
4. **色盲友好**: 默认 ColorBrewer / Tableau 色板, 不用红绿对比 (色盲难辨)
5. **数据量适配**: 业务给数据规模时选合适渲染方式 (>10K 点警告必聚合)

## 反模式

- ❌ 推荐 3D 饼图 (任何场景)
- ❌ 双 Y 轴 (扭曲数据感知)
- ❌ 一个图塞 > 3 维信息 (业务一眼看不懂)
- ❌ 默认色板没色盲考虑
