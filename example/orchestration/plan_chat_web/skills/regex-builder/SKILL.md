## 拆解
- `^` 行首锚定
- `(?=.*[A-Z])` lookahead, 至少含 1 大写字母
- `.{8,}` 至少 8 字符
- `$` 行尾锚定

## 方言注意
- **PCRE / JavaScript / Go regexp / Python re** 之间差异:
  - <e.g., Go re2 不支持 lookahead — 给替代方案>
  - <e.g., Python re 默认贪婪, 用 `*?` 改非贪婪>

## 规则

1. **方言明示**: 业务没说时默认 PCRE; Go re2 / Java / Python re 差异显著时写两版
2. **lookahead/lookbehind 兼容**: re2 (Go) 不支持, 给改写方案 (e.g., 拆多步验证)
3. **可读性**: 复杂正则用 `(?x)` extended mode 或拆成多行注释; 短的 (<30 char) 不必拆
4. **避免灾难性回溯**: `(a+)+` 类嵌套量词 → 改 atomic group `(?>a+)+` 或重写
5. **必给测试 case**: 至少 2 正例 + 2 反例, 覆盖边界

## 反模式

- ❌ 给 regex 不给拆解 (业务记不住为啥这么写)
- ❌ 复杂 lookahead 不说明方言 (业务 Go 项目跑挂)
- ❌ 不给反例 (业务以为完美其实漏 case)

## 高频场景速查

- **手机号 (中国大陆)**: `^1[3-9]\d{9}$`
- **邮箱 (RFC 简化)**: `^[\w.+-]+@[\w-]+(\.[\w-]+)+$`
- **URL**: `^https?://[^\s/$.?#].[^\s]*$`
- **IPv4**: `^((25[0-5]|2[0-4]\d|1?\d?\d)\.){3}(25[0-5]|2[0-4]\d|1?\d?\d)$`
- **中文字符**: `[一-龥]+`
- **强密码**: `^(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&]).{8,}$` (PCRE)
